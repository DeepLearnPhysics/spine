Cluster Module
==============

The :mod:`spine.cluster` package provides shared cluster formation,
measurement, direction, labeling, topology, and graph operations. These
routines understand SPINE cluster and batch products. Array-only numerical
primitives remain in :mod:`spine.math`; model-specific graph construction
remains with its owning model package.
